# AGENTS.md

## Conventions

- Agent skills live in `.agents/skills/<name>/SKILL.md`. Do not use `.devin/`.
- Blog posts are Markdown files in `src/content/`. Use the `writing-style` skill when writing or rewriting them.

## Commands

- Dev server: `npm run dev` (Vite, http://localhost:5173)
- Build: `npm run build`
- Tests: `npm test`

## Commits and PRs

- Use [Conventional Commits](https://www.conventionalcommits.org/) for commit messages and PR titles, e.g. `feat: add experiences page`, `fix(experience): broken skill links`.
